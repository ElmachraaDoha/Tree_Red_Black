Search = N successful searches. Delete = all N keys in random order.
Repetitions: 5 for N <= 10,000, otherwise 3. Times are averages.
sizeof(Node) = 32 bytes (our tree: peak memory is about peak nodes x 32 bytes).

=====================================================================
 NOTES
=====================================================================
* Rotations, recolorings and memory allocations can only be counted in
  our tree. std::map hides its inside (the C++ standard does not even
  say it must be a Red-Black tree), so we do not show them for std::map.
* Comparisons: tree = 1 per node visited. map = number of calls of its
  comparator. They are close, but not identical (erase(key) in std::map
  calls the comparator more often).
* Theory: search, insertion and deletion are O(log n) in both, because
  the height of a Red-Black tree is at most 2 * log2(n + 1).
